Kebijakan Privasi

Berlaku sejak 11 November 2026 · KLIP CUAN Clipper

1. Siapa kami

KLIP CUAN Clipper ("aplikasi") adalah alat pribadi yang dipakai oleh pengelola channel KLIP CUAN untuk menyunting video pendek dan mengunggahnya ke akun KLIP CUAN sendiri di YouTube, TikTok, dan Instagram. Aplikasi berjalan di komputer pengelola dan tidak dibuka untuk pengguna umum.

2. Data yang diakses

Saat pengelola menghubungkan akunnya sendiri, aplikasi menerima melalui API resmi platform:

  • Token akses (OAuth) untuk akun KLIP CUAN;
  • Info profil dasar akun KLIP CUAN (nama tampilan, ID akun, jumlah pengikut);
  • Statistik video yang diunggah oleh akun KLIP CUAN (penayangan, suka, komentar, bagikan).

Aplikasi tidak mengakses data pengguna lain, tidak membaca pesan pribadi, dan tidak mengumpulkan data penonton.

3. Cara data digunakan

Data hanya dipakai untuk mengunggah video ke akun KLIP CUAN dan menampilkan statistik kinerja video di dashboard pribadi pengelola.

4. Penyimpanan & keamanan

Token dan kredensial disimpan terenkripsi (Windows DPAPI) hanya di komputer pengelola. Data tidak dijual, tidak dibagikan, dan tidak dikirim ke server pihak ketiga selain server resmi platform terkait (Google/YouTube, TikTok, Meta/Instagram).

5. Pencabutan akses

Akses dapat dicabut kapan saja dengan menekan "Putuskan" di aplikasi, atau melalui pengaturan keamanan/aplikasi terhubung di akun YouTube, TikTok, atau Instagram. Setelah dicabut, token dihapus dari komputer pengelola.

6. Kontak

Pertanyaan tentang kebijakan ini dapat dikirim melalui halaman channel YouTube youtube.com/@klipcuan-id (tab Tentang/About).
