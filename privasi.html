Kebijakan Privasi

Berlaku sejak 11 November 2026 · diperbarui 17 November 2026 · KLIP CUAN

1. Siapa kami

KLIP CUAN Clipper ("aplikasi") adalah alat pribadi yang dipakai oleh pengelola channel KLIP CUAN untuk menyunting video pendek dan mengunggahnya ke akun KLIP CUAN sendiri di YouTube, TikTok, dan Instagram. Aplikasi berjalan di komputer pengelola dan tidak dibuka untuk pengguna umum.

2. Data yang diakses

Saat pengelola menghubungkan akunnya sendiri, aplikasi menerima melalui API resmi platform:

  • Token akses (OAuth) untuk akun KLIP CUAN;
  • Info profil dasar akun KLIP CUAN (nama tampilan, ID akun, jumlah pengikut);
  • Statistik video yang diunggah oleh akun KLIP CUAN (penayangan, suka, komentar, bagikan).

Aplikasi tidak mengakses data pengguna lain, tidak membaca pesan pribadi, dan tidak mengumpulkan data penonton.

3. Cara data digunakan

Data hanya dipakai untuk mengunggah video ke akun KLIP CUAN dan menampilkan statistik kinerja video di dashboard pribadi pengelola.

4. Penyimpanan & keamanan

Token dan kredensial disimpan terenkripsi (Windows DPAPI) hanya di komputer pengelola. Data tidak dijual dan tidak dibagikan. Data hanya dikirim ke server resmi platform terkait (Google/YouTube, TikTok, Meta/Instagram). Untuk fitur penulisan naskah, judul dan cuplikan berita publik (bukan data pengguna) dikirim ke layanan AI Anthropic (Claude API).

5. Toko Lynk & situs artikel

Toko KLIP CUAN di Lynk (lynk.id/klipcuanid) memakai Google Analytics 4 melalui Google Tag Manager untuk mengukur kunjungan: halaman yang dilihat, perkiraan lokasi dan jenis perangkat, serta sumber kunjungan (misalnya tautan dari video YouTube kami). Google Analytics memasang cookie analitik (_ga) di peramban pengunjung.

  • Data ini hanya dipakai untuk mengetahui konten mana yang bermanfaat bagi penonton, bukan untuk iklan.
  • Opsi berbagi data opsional ke Google di Google Analytics kami nonaktifkan.
  • Untuk menolak pengukuran, blokir cookie pihak ketiga di peramban Anda atau pasang add-on penolakan Google Analytics.
  • Data pembelian (nama, email, pembayaran) diproses oleh Lynk sesuai kebijakan privasi Lynk. KLIP CUAN tidak menyalin data pembeli ke aplikasi ini.

Situs artikel ini (webpenelitian-cpu.github.io/klipcuan) tidak memakai analitik atau cookie. Video yang disematkan dimuat dari youtube-nocookie.com (mode privasi YouTube).

6. Pencabutan akses

Akses dapat dicabut kapan saja dengan menekan "Putuskan" di aplikasi, atau melalui pengaturan keamanan/aplikasi terhubung di akun YouTube, TikTok, atau Instagram. Setelah dicabut, token dihapus dari komputer pengelola.

7. YouTube API Services

Aplikasi ini menggunakan YouTube API Services. Dengan menghubungkan akun YouTube, pengguna tunduk pada Persyaratan Layanan YouTube, dan data yang diproses Google tunduk pada Kebijakan Privasi Google. Akses aplikasi ke akun Google dapat dicabut kapan saja melalui halaman izin keamanan akun Google.

Data API YouTube yang tersimpan hanyalah data akun KLIP CUAN sendiri yang diotorisasi (statistik video sendiri), dipakai untuk riwayat kinerja di dashboard pribadi. Token dihapus dari komputer pengelola segera setelah akses dicabut; riwayat statistik dihapus atas permintaan lewat kontak di bawah. Aplikasi tidak menyimpan atau membaca informasi di perangkat orang lain dan tidak membagikan data API YouTube kepada pihak ketiga.

YouTube API Services (English summary)

KLIP CUAN Clipper uses YouTube API Services. By connecting a YouTube account, users agree to be bound by the YouTube Terms of Service; Google's handling of data is governed by the Google Privacy Policy.

What the app accesses: the OAuth token, basic profile of our own channel, and statistics of videos uploaded by our own channel. How it is used: to upload and schedule videos to our own channel and to show performance statistics on a private dashboard. The app does not sell or share YouTube API data with third parties and does not store or access information on other users' devices.

Storage and deletion: tokens are stored encrypted (Windows DPAPI) only on the operator's computer. The only stored YouTube API data is authorized data of our own channel (statistics of our own videos), kept as performance history on the private dashboard. Access can be revoked at any time in the app ("Putuskan") or via the Google security settings page; the token is then deleted immediately. Stored statistics are deleted on request via the contact below.
